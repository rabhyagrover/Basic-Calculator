# Basic-Calculator
A lightweight, terminal-based calculator built with Python. This project demonstrates fundamental programming concepts such as functions, user input handling, error management (try-except blocks), and conditional logic.
🚀 Features
Basic Arithmetic: Supports Addition, Subtraction, Multiplication, and Division.

Error Handling: Gracefully handles non-numeric inputs and prevents crashes from division by zero.

Continuous Execution: A recursive-style loop that allows for multiple calculations without restarting the script.

Clean Code: Modular design with specific functions for each mathematical operation.

📖 How it Works
The program prompts the user to select an operation and enter two numbers. It converts inputs to floats to support decimal calculations. If an invalid input is detected, the program notifies the user and prompts for input again rather than exiting.
